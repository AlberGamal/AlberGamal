## Flagship projects

### [MeetIQ — AI Meeting Intelligence Platform](https://github.com/AlberGamal/MeetIQ)

A meeting intelligence workspace that turns audio and video recordings into speaker-aware transcripts, summaries, decisions, action items, sentiment, analytics, semantic search, and PDF reports. The system combines Deepgram transcription and diarization, grounded LLM analysis, local multilingual embeddings, TiDB vector retrieval, ownership-scoped access, and callback-driven background processing with stale-job recovery.

**Stack:** React, TypeScript, Vite, Node.js, Express, tRPC, Drizzle ORM, TiDB/MySQL, Deepgram, Transformers.js, ONNX, Vitest, Docker-oriented deployment.

### [Aegis Predictive Maintenance AI](https://github.com/AlberGamal/aegis-predictive-maintenance)

An industrial monitoring platform built around deterministic sensor simulation and persisted time-series workflows. Aegis combines feature engineering, a TypeScript gradient-boosting production model, an independent anomaly detector, health and risk scoring, exact additive-tree Shapley explanations, persistent alerts, maintenance history, and a TensorFlow.js LSTM comparison model.

**Stack:** React, TypeScript, Node.js, Express, tRPC, Drizzle ORM, MySQL/TiDB, TensorFlow.js, Recharts, Docker Compose, Vitest.

### [Fraud Investigation System](https://github.com/AlberGamal/fraud-investigation-system)

A research-oriented analyst workspace for synthetic financial fraud data. It brings together causal and temporal feature engineering, supervised model comparisons, XGBoost scoring, Isolation Forest anomaly detection, persisted SHAP explanations, risk scoring, alerts, investigations, data-quality events, drift reporting, and API metrics behind a protected FastAPI service.

**Stack:** React, TypeScript, Vite, Tailwind CSS, FastAPI, SQLAlchemy, PostgreSQL, pandas, scikit-learn, XGBoost, SHAP, Docker Compose.

### [TalentIQ — AI Recruitment Intelligence Platform](https://github.com/AlberGamal/talentiq-ai-recruitment-platform)

An evidence-first recruitment workspace for structured job authoring, job-description analysis, PDF/DOCX resume ingestion, background processing, candidate profiling, skill-gap analysis, semantic retrieval, explainable hybrid ranking, grounded explanations, interview intelligence, evaluation, and fairness views. The ranking engine keeps explicit requirements and evidence inspectable rather than relying on opaque similarity alone.

**Stack:** React, TypeScript, Vite, FastAPI, SQLAlchemy, SQLite/PostgreSQL, pgvector, PyMuPDF, python-docx, local embeddings, optional OpenAI-compatible AI providers, Docker Compose.
